📤 Экспорт всех данных

Скачайте данные бота. Архив содержит актуальную структуру всех файлов с информацией для пользователей и бд админов :

  • db/ — базы данных (пользователи, вишлисты)
  • map/ — карты ярмарки
  • participants/ — список участников
  • recs/ — рекомендации книг
  • timetables/ — расписания мероприятий
⬇️ Скачать архив assets.zip

📥 Импорт данных из архива

Загрузите ZIP-архив с ассетами. Вы можете выполнить полный импорт или заменить только выбранный раздел.

⚠️ Внимание: файлы выбранных разделов будут полностью перезаписаны данными из архива!

ℹ️ О структуре архива

Вы также можете использовать командную строку не сервере для импорта и экспорта:

# Экспорт всех данных в ZIP:
python -m admin export [assets_backup.zip]
# Полный импорт:
python -m admin import assets_backup.zip
# Частичный импорт (например, только расписания или карта):
python -m admin import assets_backup.zip --component timetables
# Выборочный импорт нескольких разделов:
python -m admin import assets_backup.zip --component recs timetables
